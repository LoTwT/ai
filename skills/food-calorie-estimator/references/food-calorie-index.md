# 个人食物热量索引（快查表）

> 用户常吃食物的热量参照表，供 **快速查询**，避免每次重新估算，同时保证同一食物跨餐次一致。
> 由 `food-calorie-estimator` 在估算时**优先查询**（数据获取优先级 step 0），并在算出新食物后**追加/更新**。

## 怎么用

- **查询**：按食物名找到行 → `热量 = 每100g热量 × 你的重量(g) ÷ 100`。
  - 例：白米饭(熟) 116 kcal/100g，吃 200g → 116 × 200 ÷ 100 = 232 kcal。
- **品牌整份固定**（如连锁奶茶/咖啡的某杯型 SKU）：份量与热量绑定，直接用「整份热量」列，不按每100g 折算。
- **命中即用**：estimator 估算时先查这张表；命中（同一或高度相似食物）→ 直接用，跳过重新查询，且与历史一致。
- **未命中**：estimator 走常规流程算出后，把结果**追加**到本表（食物名 + 每100g热量 [+ 典型份量] + 备注/来源）。

## 字段说明

| 字段 | 说明 |
|---|---|
| 食物 | 食物名（含关键规格，如「炒饭」「白米饭(熟)」「生椰拿铁(大杯)」） |
| 每100g热量(kcal) | 成品每 100g 热量；可复用于任意份量。品牌整份固定的留空，用「整份热量」 |
| 整份热量(kcal) | 仅品牌 SKU / 份量固定项填写（如某杯型整杯热量） |
| 典型份量 | 该食物常见份量，便于快速心算（可选） |
| 备注/来源 | 数据来源（成品估 / 品牌 SKU / 包装标签 / Web）或备注 |

## 维护原则

- **保守取高**：沿用 estimator 原则，不确定时存偏高值。
- **来源标注**：尽量标来源，便于日后校正。
- **去重**：同一食物已存在则更新，不重复追加。
- **保持有序**：按类别分组（主食 / 菜 / 蛋白 / 饮品 / 零食…）或按拼音排，让「快查」在表变长后仍快；条目多了可拆成分类小表。
- 本表是**用户个人**累积数据，随饮食习惯增长。
